## 1. 講座申し込みフォームについて

講座申し込みフォームでは、**2026年夏期講座シリーズ**（8月1日〜9月13日）の開催時間を予約できます。

ログイン済みのメンバーが対象です。未ログインの場合は、画面右上の **「Discordでログイン」ボタン** からログインしてください。

> **重要:** 同じ時間帯には1つの講座しか予約できません（先着順）。

---

## 2. 画面の見方

画面は大きく3つのエリアに分かれています。

```
┌──────────────────────────────────────────────────┐
│  📅 講座申し込みフォーム        [@ユーザー名]      │
│  8月1日〜9月13日  同時間帯は先着順（1枠のみ）      │
├─────────────────────────────┬────────────────────┤
│                             │                    │
│   ◀ 前週   8/4〜8/10  次週 ▶│   📝 予約フォーム    │
│                             │                    │
│   [週間カレンダー]            │   タイトル:         │
│   月 火 水 木 金 土 日        │   Discord名:       │
│   ┌──┬──┬──┬──┬──┬──┬──┐    │   日付:            │
│   │  │  │予│  │  │  │  │    │   時間:            │
│   │  │  │約│  │  │  │  │    │   メモ:            │
│   │  │  │済│  │  │  │  │    │                    │
│   └──┴──┴──┴──┴──┴──┴──┘    │   [申し込む]        │
│                             │                    │
│   📋 全予約一覧（N件）         │                    │
│                             │                    │
└─────────────────────────────┴────────────────────┘
```

| エリア | 説明 |
|--------|------|
| **週間カレンダー**（左上） | 各日の予約状況を視覚的に表示。ドラッグで時間帯を選択可能 |
| **予約フォーム**（右） | 講座の詳細情報を入力して申し込み |
| **全予約一覧**（左下） | 登録済みの全講座を一覧表示 |

## 3. 講座を申し込む（新規予約）

### 3-1. カレンダーからドラッグで選択する

1. 週間カレンダー上で、希望する日時の**空き枠をドラッグ**します（マウスを押しながら上下に動かす）。
2. 選択された時間帯がハイライトされ、右側のフォームに日時が自動入力されます。
3. フォームで **講座タイトル** などを入力します。
4. **「申し込む」ボタン** をクリックします。
5. 「申し込みが完了しました！🎉」と表示されれば成功です。

### 3-2. フォームから直接入力する

1. 右側のフォームに以下の情報を入力します。
2. **「申し込む」ボタン** をクリックします。

### フォーム入力項目

| 項目 | 必須 | 説明 |
|------|:----:|------|
| **講座タイトル** | ✓ | 講座の名前 |
| **Discord名** | ✓ | 申し込み者のDiscord名（ログイン時は自動入力） |
| **日付** | ✓ | 開催日（予約可能期間内） |
| **開始時刻** | ✓ | 講座の開始時刻 |
| **終了時刻** | ✓ | 講座の終了時刻（開始より後である必要あり） |
| **メモ** | — | 補足情報（任意） |

## 4. 予約済み講座を編集する

自分が登録した講座を編集できます（admin は全講座を編集可能）。

1. カレンダー上の予約済みブロック、または予約一覧から **「編集」ボタン** をクリックします。
2. 右側のフォームが **編集モード** に切り替わり、現在の内容が入力されます。
3. 変更したい内容を修正します。
4. **「更新」ボタン** をクリックします。
5. 確認ダイアログが表示されます。**「更新する」** をクリックして確定します。
6. 「講座を更新しました ✅」と表示されれば成功です。

> **編集をキャンセル** したい場合は、フォーム内の **「キャンセル」ボタン** をクリックします。

---

## 5. 予約済み講座を削除する

自分が登録した講座を削除できます（admin は全講座を削除可能）。

1. カレンダー上の予約済みブロック、または予約一覧から **「削除」ボタン** をクリックします。
2. 確認ダイアログが表示されます。**「削除する」** をクリックして確定します。
3. 「講座を削除しました」と表示されれば成功です。

---

## 6. 週の切り替え

カレンダー上部の **◀（前週）** **▶（次週）** ボタンで、表示する週を切り替えられます。

現在表示中の週の日付範囲がナビゲーター中央に表示されます。

---

## 7. 注意事項・制約

| 項目 | 説明 |
|------|------|
| **予約可能期間** | 2026年8月1日〜2026年9月13日 |
| **時間帯の重複** | 同じ日・同じ時間帯には1つの講座のみ予約可能（先着順） |
| **編集・削除権限** | 自分が作成した講座のみ編集・削除可能。admin はすべての講座を操作可能 |
| **エラー「選択した時間帯はすでに予約されています」** | 他の講座と時間が重なっています。別の時間帯を選択してください |
