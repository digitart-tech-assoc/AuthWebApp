## 1. このページでできること

`/roles` ページは、**Discordサーバーのロール（役割）を管理する**ための画面です。

ここで行った変更は、このシステムのデータベース（DB）への保存と、Discordへの自動反映が**同時に**行われます。別途Discordを操作する必要はありません。

> **ロールとは？**  
> Discordでいう「役割」のことです。構成員のグループ分けに使われます。

---

## 2. ログイン種別による機能の違い

このシステムには **admin（管理者）** と **member（一般メンバー）** の2種類のログインがあります。ログイン種別によって、表示される画面と操作できる内容が異なります。

| 機能 | admin | member |
|------|:-----:|:------:|
| 自分のロールを確認する | ✓ | ✓ |
| 自分のロールを自分で付与・削除する | ✓ | ✓（管理者専用カテゴリは除く） |
| ロールを新しく作成する | ✓ | ✓ |
| ロールを編集する（名前・色など） | ✓ | ✗ |
| ロールを削除する | ✓ | ✗ |
| ロールの権限を設定する | ✓ | ✗ |
| 他のメンバーへロールを付与・削除する | ✓ | ✗ |
| カテゴリを作成する | ✓ | ✓ |
| カテゴリを編集する（名前・専用設定） | ✓ | ✗ |
| カテゴリを削除する | ✓ | ✗ |
| カテゴリの権限を設定する | ✓ | ✗ |
| メンバーリストをDiscordから同期する | ✓ | ✗ |

## 3. 【member ログイン時】ロール画面の使い方

member でログインすると、「**マイロール**」という個人向けの画面が表示されます。

### 3-1. 画面の見方

画面上部に自分のプロフィールカード（名前・Discordアイコン）と、現在自分に付与されているロールの一覧が表示されます。

その下の「**ロールカテゴリ**」セクションに、各カテゴリとその中のロールが表示されます。

```
┌─────────────────────────────────────┐
│  👤 山田 太郎                       │
│  Discord ID: 1234567890             │
│  現在のロール（2件）                  │
│   ● member   ● B1                   │
└─────────────────────────────────────┘

ロールカテゴリ（例）
  ▼ 学年               [ロールの数]
    ● B1                ✕ 削除
    ● B2                ＋ 付与
    ● B3                ＋ 付与
    ...

  ▼ 会員情報           [ロールの数]
    ● administrator    変更不可
    ● member           変更不可
    ...

  ▼ ロール一覧         [ロールの数]
    ● B1   付与済み
    ...
```

### 3-2. 自分のロールを追加する

1. 「ロールカテゴリ」の中から、追加したいロールを探します。
2. ロール名の右側にある **「＋ 付与」ボタン** をクリックします。
3. 画面下部に **「未送信の変更があります」** というバーが出てきます。
4. **「変更を確定」ボタン** をクリックします。
5. しばらく待つと自動的にDBへの保存とDiscordへの反映が行われ、成功するとページがリロードされます。

**「＋ 付与」をクリックしただけでは、まだ変更は確定していません。必ず「変更を確定」を押してください。**

### 3-3. 自分のロールを削除する

1. 現在付与されているロールの右側にある **「✕ 削除」ボタン** をクリックします。
2. 画面下部に **「未送信の変更があります」** バーが出てきます。
3. **「変更を確定」ボタン** をクリックします。
4. 自動的にDBへの保存とDiscordへの反映が行われます。

### 3-4. 操作できないロールについて
| 表示 | 意味 |
|------|------|
| **変更不可** | 「管理者専用」カテゴリのロールです。adminのみが操作できます。 |

### 3-5. ロール一覧

画面下部の「**ロール一覧**」セクションでは、Discordサーバーに存在するすべてのロールを確認できます。自分が持っているロールには「付与済み」と表示されます。ここは確認専用であり、付与・削除の操作はできません。

## 4. 【admin ログイン時】ロール管理画面の使い方

admin でログインすると、「**ロール管理**」という管理者向けの全機能画面が表示されます。

### 4-1. 画面の基本構成

```
（例）
┌───────────────────────────────────────────────────┐
│  ロール管理                                        │
│  Discord サーバーのロールとカテゴリ、権限を管理できます│
│  ───────────────────────────────────────────────  │
│  [ロールを検索...] [+ ロール作成] [⊙ カテゴリ作成]  │
│  ─────────────────────────────────────────────── │
│  adminモード: すべての管理操作が有効です。          │
│                                                  │
│  ▼ 会員情報     [3]  [編集] [🛡権限] [✕]          │
│    ⠿ ● mentor   メンバー 編集 🛡権限 ✕            │
│    ⠿ ● member   メンバー 編集 🛡権限 ✕            │
│    ⠿ ● advisor   メンバー 編集 🛡権限 ✕           │
│    ...                                           │
│  ▼ ロール一覧 [全件]                              │
│    ● 1年生   メンバー                             │
│    ...                                           │
│                                                  │
│  ┌────────────────────────────────┐              │
│  │ メンバーリスト管理               │              │
│  │ [Discord から同期]              │              │
│  └────────────────────────────────┘              │
└──────────────────────────────────────────────────┘
```

### 4-2. ロールを新しく作る

1. 画面上部の **「+ ロール作成」ボタン** をクリックします。
2. モーダル（ポップアップ）が表示されます。

**【基本設定タブ】**

| 項目 | 説明 |
|------|------|
| **ロール名** | ロールの名前を入力します。（必須） |
| **カテゴリ** | このロールを所属させるカテゴリを選択します。カテゴリなしを選択した場合、「ロール一覧」のみに表示されます。 |
| **カラー** | ロールの色をパレットから選ぶか、16進数カラーコード（例: `#FF5733`）で直接入力します。 |
| メンバーをオンライン一覧で分けて表示（Hoist） | **固定: オフ**（変更不可） |
| このロールを誰でもメンションできるようにする（Mentionable） | **固定: オン**（変更不可） |

**【権限設定タブ】**

基本この部分の設定をすることはないですが、ロール固有の権限を設定したい場合に有効です。基本設定で任意のカテゴリを選択すると、そのカテゴリの権限が初期値として自動で引き継がれます。必要に応じて個別に変更できます。

1. 設定が完了したら **「作成」ボタン** をクリックします。この直後、[4-6. ロールにメンバーを割り当てる・外す](#4-6-ロールにメンバーを割り当てる外す)の操作を行うことで、ロールの作成と該当者への割り当てを一括で行うことができます。
2. 画面下部に「未送信の変更があります」バーが出ます。
3. **「変更を確定」ボタン** をクリックして確定します。

### 4-3. ロールを編集する

1. 編集したいロールの行にある **「編集」ボタン** をクリックします。
2. ロール作成と同じモーダルが「編集モード」として開きます。
3. 変更したい項目を修正し、**「更新」ボタン** をクリックします。
4. 「変更を確定」をクリックして確定します。

### 4-4. ロールを削除する

1. 削除したいロールの行にある **「✕」ボタン** をクリックします。
2. 確認ダイアログが表示されます。「OK」をクリックします。
3. ロールが一覧から消えます。「変更を確定」をクリックして確定します。

> **注意:** Botのロールより上位に位置するロール（グレーアウトしているロール）は削除できません。

### 4-5. ロールの並び順を変える（ドラッグ）

カテゴリ内のロール一覧で、ロール名の左側にある **「⠿」（ドラッグハンドル）** をドラッグ＆ドロップすることで、ロールの順番を変更できます。

1. ドラッグハンドル **「⠿」** をマウスでつかんだまま（長押し）動かします。
2. 移動したい位置で離します。
3. 「変更を確定」をクリックして確定します。

> **注意:** Botのロール以上の位置にあるロールはドラッグできません（「不可」状態として半透明表示になります）。

Discordアプリ上のロール一覧で表示される並び順は、「ロール一覧」カテゴリの並び順を参照しているので、ロールの順序を入れ替える操作を適宜行ってください。特に新規ロール作成後は、最下層に作られるので、ドラッグによって適切な階層まで移動させてください。

### 4-6. ロールにメンバーを割り当てる・外す

各ロールの **「メンバー」ボタン** をクリックすると、そのロールを持つメンバーの一覧と操作画面が開きます。

**ロールを付与する（メンバーを追加する）**

1. ロールの「メンバー」ボタンをクリックします。
2. メンバー一覧モーダルが開きます。「**付与**」ボタンをクリックします。
3. 付与したいメンバーを検索して選択します（チェックボックスで複数選択可能）。
4. **「決定（X名）」ボタン** をクリックします。
5. メンバー一覧に戻るので、内容を確認して **「変更を確定」ボタン** をクリックします。
6. メインのロール管理画面に戻り、画面下部の「変更を確定」をクリックして最終確定します。

**ロールを解除する（メンバーを削除する）**

1. ロールの「メンバー」ボタンをクリックします。
2. 「**削除**」ボタンをクリックします。
3. 解除したいメンバーを選択します。
4. **「削除（X名）」ボタン** をクリックします。
5. メンバー一覧に戻り、**「変更を確定」ボタン** をクリックします。
6. メインの「変更を確定」をクリックして最終確定します。

> **ヒント:** 「ロール一覧」セクションのメンバーボタンは閲覧専用です。付与・削除はカテゴリ内のロールから行ってください。

### 4-7. カテゴリを作る

カテゴリとは、複数のロールをまとめてグループ化する機能です。

1. 画面上部の **「⊙ カテゴリ作成」ボタン** をクリックします。
2. 「選択モード」になり、各ロールの左側にチェックボックスが表示されます。
3. このカテゴリに含めたいロールにチェックを入れます（複数選択可）。空のカテゴリも作成可能です。
4. 画面上部の入力欄に **カテゴリ名** を入力します。
5. （任意）「**管理者専用**」チェックボックスをオンにすると、memberユーザーはこのカテゴリ内のロールを自分で付与・削除できなくなります。
6. **「作成」ボタン** をクリックします。
7. メインの「変更を確定」をクリックして確定します。

> **「管理者専用」チェックについて:**  
> このチェックをオンにすると、member がロール管理ページを使っても、このカテゴリのロールは「**変更不可**」と表示され、操作できなくなります。学年・学部などシステムで管理すべきロールに使うと便利です。

### 4-8. カテゴリを編集する

1. 編集したいカテゴリのヘッダー行にある **「編集」ボタン** をクリックします。
2. 編集モーダルが開きます。

| 項目 | 説明 |
|------|------|
| **カテゴリ名** | カテゴリの表示名を変更できます。（必須） |
| **管理者専用カテゴリ** | オンにすると、memberはこのカテゴリのロールを操作できなくなります。オフにすると操作可能になります。 |

3. 変更したら **「保存」ボタン** をクリックします。
4. メインの「変更を確定」をクリックして確定します。

### 4-9. カテゴリを削除する

1. 削除したいカテゴリのヘッダー行にある **「✕」ボタン** をクリックします。
2. 確認ダイアログが表示されます。「OK」をクリックします。
3. カテゴリが削除されます。カテゴリ内にあったロールは「ロール一覧」に残ります。（ロール自体は削除されません）。
4. メインの「変更を確定」をクリックして確定します。

### 4-10. カテゴリの並び順を変える（ドラッグ）

カテゴリのヘッダー行にある **「⠿」（ドラッグハンドル）** をドラッグ＆ドロップして、カテゴリの表示順を変更できます。

1. カテゴリヘッダーの「⠿」をつかんだまま動かします。
2. 移動したい位置で離します。
3. 「変更を確定」をクリックして確定します。

### 4-11. ロール・カテゴリの権限を設定する

権限とは、Discordサーバー上でそのロールに与える操作権限（メッセージ送信、チャンネル管理など）のことです。

**カテゴリの権限を設定する**

1. カテゴリヘッダー行の **「🛡 権限」ボタン** をクリックします。
2. 右側に「権限エディター」パネルが開きます。
3. 各権限のトグルスイッチをオン/オフで切り替えます。
4. **「保存」ボタン** をクリックします。
   - カテゴリの権限を保存すると、そのカテゴリ内にある**すべてのロールに同じ権限が自動で適用**されます。
5. メインの「変更を確定」をクリックして確定します。

**ロールの権限を設定する**

1. ロール行の **「🛡 権限」ボタン** をクリックします。
2. 権限エディターパネルが開きます。
3. 権限を設定して「保存」をクリックします。
4. メインの「変更を確定」をクリックして確定します。

> **「Bot権限不足」と表示されているものについて:**  
> DiscordのBotがその権限を持っていないため、設定できません。Discordサーバー側でBotのロールに権限を追加する必要があります。

### 4-12. 変更を確定してDiscordに反映する

ロールの追加・削除・編集・メンバー変更などを行った後、**画面下部に「未送信の変更があります」バーが表示**されます。

1. バー内の **「変更を確定」ボタン** をクリックします。
2. 変更内容の確認ダイアログが表示されます。

   ```
   （例）
   変更内容の確認
   以下の変更をDBに保存し、Discordへ同期します

   ＋ ロールを追加（1件）
     BBQ(20XX年度)

   👥 メンバーを割り当て（1件）
     BBQ(20XX年度)
       ➕ 2名追加

   [キャンセル]  [保存してDiscordへ送信]
   ```

3. 内容を確認し、**「保存してDiscordへ送信」ボタン** をクリックします。
4. 「DBに保存中...」→「Discordへ同期中...」の順にメッセージが表示されます。
5. 成功するとページがリロードされます。

> **キャンセルしたい場合:** 「キャンセル」をクリックすると、確認ダイアログを閉じて編集状態に戻ります。変更内容は保持されます。変更内容を破棄したい場合は、ページを強制リロードするか逆の操作を行う必要があります。

### 4-13. メンバーリストの管理（Discord同期）

画面下部の「**メンバーリスト管理**」セクション（adminのみ表示）では、Discordサーバーのメンバー情報を取り込む操作が行えます。

- **「Discord から同期」ボタン** をクリックすると、最新のDiscordメンバー情報をこのシステムに取り込みます。
- 「メンバー」「管理者」「入会予定メンバー」の3グループに分けて表示されます。

> ロールをメンバーに割り当てる際（4-6参照）に表示されるメンバー一覧は、この同期で取得した情報から表示されます。新しいメンバーが加入した際は、この同期を実行してください。

## 5. よくある疑問・注意事項

### ❓ 変更したのにDiscordに反映されていない

「変更を確定」ボタンを押し忘れている可能性があります。画面下部に「**未送信の変更があります**」バーが表示されていないか確認してください。

### ❓ 「DB保存は完了しましたが、Discordへの送信に失敗しました」と表示される

このシステムのデータベースへの保存には成功しています。Discordへの反映のみ失敗した状態です。Discord側の一時的な障害の可能性があるので、しばらく待ってから再度お試しください。

### ❓ 操作後にページが自動更新される

ロールの変更確定後、正常に完了するとページが自動で更新されます。これは正常な動作です。

### ❓ ロールを削除したらカテゴリも消えた？

カテゴリは消えていません。カテゴリを削除した場合、そのカテゴリに属していたロールは「ロール一覧」に残ります。ロール自体は保持されています。
