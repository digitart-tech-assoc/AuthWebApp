## 1. お問い合わせフォームについて

お問い合わせフォーム（`/contact`）では、サークル運営への質問・要望・バグ報告などを送信できます。

**ログイン不要** でどなたでもご利用いただけます。

---

## 2. フォームの入力と送信

1. 各項目を入力します（必須項目は `*` 印あり）。
2. 入力内容を確認し、**「送信」ボタン** をクリックします。
3. 「お問い合わせを送信しました。返信までしばらくお待ちください。」と表示されれば送信完了です。

---

## 3. 入力項目

| 項目 | 必須 | 説明 |
|------|:----:|------|
| **氏名** | ✓ | 「姓 名」の形式（半角スペース区切り）。例: 田中 太郎 |
| **メールアドレス** | ✓ | 返信に使用するメールアドレス |
| **メールアドレス（確認）** | ✓ | 確認のため同じメールアドレスを再入力 |
| **所属** | — | 例: 青山学院大学 理工学部 |
| **件名** | — | お問い合わせの件名 |
| **本文** | — | お問い合わせの内容 |

### 入力時の注意

- **氏名** は必ず「姓（半角スペース）名」の形式で入力してください。形式が正しくない場合、送信ボタンが無効になります。
- **メールアドレス** と **メールアドレス（確認）** が一致しない場合、「メールアドレスが一致しません。」とエラーが表示されます。

---

## 4. メールアドレスの検証について

メールアドレスを入力すると、自動的に **ドメインのMXレコード検証** が行われます。

| 表示 | 意味 |
|------|------|
| 「メールサーバーを確認中…」 | 検証処理中です。しばらくお待ちください。 |
| 「受信可能なドメインが見つかりました。」（緑色） | メールアドレスのドメインが有効です。 |
| 「メールサーバーが見つかりません。」（赤色） | メールアドレスのドメインに問題がある可能性があります。入力をご確認ください。 |
| 「入力後にドメインのMXレコードを確認します」 | まだ検証が開始されていません。 |

> **注意:** MXレコード検証はネットワークの影響で検証できない場合があります。検証できなくても送信は可能です。

---

## 5. 送信後の流れ

- 送信が完了すると、運営メンバーに通知されます。
- **返信まで数日かかる場合があります。** 件名に要点を明記していただくと、スムーズに対応できます。
