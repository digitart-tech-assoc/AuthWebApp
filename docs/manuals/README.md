# AuthWebApp ユーザーマニュアル

**Digitart テクノロジー愛好会 メンバー管理システム**

> 最終更新: 2026-08-21

---

## このマニュアルについて

このマニュアルは、AuthWebApp（Digitart テクノロジー愛好会のメンバー管理Webアプリケーション）を利用するすべてのユーザーを対象としています。

AuthWebApp では、Discord アカウントを使ったログイン、サークルへの入会手続き、ロール（役割）管理、講座の申し込み、お問い合わせなどの機能を利用できます。

---

## ユーザー種別と利用可能な機能

ログインしているアカウントの権限によって、利用できる機能が異なります。

| 機能 | 未ログイン | pre-member | member(obog) | admin |
|------|:----------:|:------:|:-----:|:----:|
| 入会案内の閲覧 | ✓ | ✓ | ✓ | ✓ |
| 仮入会フォームの利用 | ✓ | ✓ | ✓ | ✓ |
| お問い合わせフォーム | ✓ | ✓ | ✓ | ✓ |
| ログイン | ✓ | — | — | — |
| 本入会フォームの利用 | — | ✓ | — | — |
| 自分のロール管理 | — | — | ✓ | — |
| プロフィール編集 | — | — | ✓ | ✓ |
| ロール・カテゴリの全管理 | — | — | — | ✓ |
| メンバー管理（入会費清算） | — | — | — | ✓ |
