## 1. ログインする

AuthWebApp では **Discord アカウント** を使ってログインします。

### 手順

1. 画面右上の **「Login」ボタン** をクリックします。
   ![ログインページ](./images/login.png)
2. ログインページが表示されます。**「Discord でログイン」ボタン**（紫色）をクリックします。
3. Discord の認証画面に移動します。内容を確認し、**「認証」**をクリックします。
   - 初回ログイン時は、Discord アカウントへのアクセス許可を求められます。
   - すでに Discord にログイン済みの場合は自動的に認証が完了します。
4. 認証が完了すると、自動的にロール管理ページ（`/roles`）にリダイレクトされます。

> **注意:** ログインには **Discord アカウントにメールアドレスが登録されている** 必要があります。メールアドレスが未設定の場合、「Discord アカウントにメールアドレスが登録されていないため、ログインできません」というエラーが表示されます。

---

## 2. ログイン後の画面

ログインに成功すると、画面上部のヘッダーに以下が表示されます：

```
┌─────────────────────────────────────────────┐
│  AuthWebApp              山田太郎  [Logout]  │
└─────────────────────────────────────────────┘
```

| 表示 | 説明 |
|------|------|
| **AuthWebApp** | クリックするとトップページに戻ります |
| **表示名** | Discord のアカウント名またはメールアドレスが表示されます |
| **Logout** | クリックするとログアウトします |

---

## 3. ログアウトする

### 方法1: ヘッダーからログアウト

画面右上の **「Logout」ボタン** をクリックすると、即座にログアウトされ、トップページに戻ります。

### 方法2: ロール管理ページからログアウト

ロール管理ページ（`/roles`）では、ページ上部にも「ログアウト」リンクが表示されています。こちらをクリックしてもログアウトできます。

## 4. ログインできない場合

| 症状 | 原因と対処 |
|------|-----------|
| 「認証に失敗しました。もう一度お試しください。」 | Discord の認証処理で問題が発生しました。ページをリロードして再度お試しください。 |
| 「Discord アカウントにメールアドレスが登録されていないため、ログインできません。」 | Discord アプリの設定画面でメールアドレスを登録してからお試しください。 |
| 「エラーが発生しました。」 | サーバーに一時的な問題が発生しています。しばらく待ってからお試しください。 |
| Discord の認証画面が表示されない | ブラウザのポップアップブロッカーが有効になっている可能性があります。設定を確認してください。 |

上記で解決しない場合は、**[お問い合わせフォーム](/contact)** から運営にご連絡ください。
