## 概要

お問い合わせページ（`/contact`）は、ユーザーからの問い合わせを受け付ける共通フォームです。氏名・メールアドレス・件名・メッセージなどを収集し、バックエンド API 経由でメール送信または問い合わせデータベースに保存されます。メール形式とMX レコード検証も実施します。

## 主要要件

- 問い合わせフォームのデータ収集
- メールアドレスの形式検証
- メールアドレスのMX レコード検証
- メールアドレスの確認（入力ミス防止）
- 氏名の形式検証（「姓<スペース>名」）
- 問い合わせ送信のサーバーアクション呼び出し
- 送信成功・失敗メッセージ表示

## 非機能要件

- リアルタイムバリデーション
- クライアントコンポーネント（React フック使用）
- メール検証時の非同期処理
- 送信完了後フォームリセット
- レスポンシブデザイン（Tailwind CSS）

## 必要項目・操作

### フォーム項目
| 項目 | 必須 | 型 | 検証 | 説明 |
|-----|------|-----|------|------|
| 氏名 | ○ | text | 「姓<空白>名」形式 | 例：田中太郎 |
| メールアドレス | ○ | email | 形式+MXレコード | RFC 5322 準拠 |
| メールアドレス（確認） | ○ | email | 一致チェック | メールアドレスと同値 |
| 件名 | × | text | なし | 最大100文字推奨 |
| 所属 | × | text | なし | 大学名など |
| メッセージ | × | textarea | なし | 詳細内容 |

## 操作

1. **ページロード時**
   - 空のフォームを表示

2. **入力フィール操作**
   - メールアドレス入力後、MX レコード検証を非同期で実行
   - 検証完了前は「検証中...」インジケータ表示
   - 氏名フィールドでリアルタイムバリデーション

3. **送信ボタン クリック**
   - 全フィールドのバリデーション実施
   - エラー時：エラーメッセージ表示、送信中止
   - 成功時：`submitContact()` サーバーアクション呼び出し
   - 送信中：ボタン無効化、ローディング表示
   - 送信完了：成功メッセージ表示 → 自動フォームリセット

## 仕様API

### サーバーアクション：submitContact
**ファイル**: `/frontend/src/actions/contact.ts`

```typescript
interface SubmitContactPayload {
  email: string;
  name: string;
  subject?: string | null;
  affiliation?: string | null;
  message?: string | null;
}

async function submitContact(payload: SubmitContactPayload): Promise<{ success: boolean }>
```

**処理内容**
- バックエンド `/api/v1/contact` へPOST送信
- メール形式再検証
- メール配信またはDB保存

## 関連DB

- 問い合わせテーブル（バックエンド）：contactテーブル（推定）
- メール配信ログ

## 備考

- MX レコード検証は外部API（Cloudflare DNS）を使用
- MX 検証失敗時は検証結果を null に設定し、入力続行可能
- 本ページは認証不要（全ユーザー対象）
- 送信成功メッセージ表示後、1秒でフォームリセット

## 実装メモ

- `validateFullName()` はバリデーション関数で `"姓 名"` 形式チェック
- MX検証のタイムアウト：応答がない場合は `null` 返却
- メール確認欄は UX 改善のための実装（ユーザー入力ミス防止）
- エラーメッセージは UI 上の赤色パネルで表示
