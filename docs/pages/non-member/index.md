## 概要

入会対象外向けページ（`/non-member`）は、Digitart テクノロジー愛好会の入会対象外のユーザーを案内するページです。サークルの説明と入会への誘導、問い合わせ導線を提供します。本ページは認証不要で全員がアクセス可能です。

## 主要要件

- サークル情報の表示（紹介文）
- 入会対象外のユーザーへの案内
- 入会フォーム へのリンク
- お問い合わせ ページへのリンク
- レスポンシブデザイン対応

## 非機能要件

- 静的ページ（ページ生成時にビルド可能）
- 認証不要
- SEO 対応（Metadata 設定）

## 必要項目・操作

### ページ構成要素
| 要素 | 内容 | リンク先 |
|-----|------|---------|
| ページ タイトル | Digitart テクノロジー愛好会へようこそ | - |
| キャッチコピー | 青山学院大学の学生による、学びと交流のコミュニティ | - |
| リード文 | サークル説明 | - |
| 仮入会ボタン | メール認証での仮入会 | `/join/form` |
| お問い合わせボタン | 不明点の相談 | `/contact` |
| カード: メンバー特典 | イベント参加・Discord招待 | `/join/form` |

## 操作

1. **ページロード時**
   - サークル紹介情報を静的表示

2. **入会フォームへ ボタン クリック**
   - `/join/form` へナビゲート
   - 入会方法選択ページへ遷移

3. **お問い合わせ ボタン クリック**
   - `/contact` へナビゲート
   - 問い合わせフォームへ遷移

## 仕様API

利用API：なし（静的ページ）

## 関連DB

なし

## 備考

- 本ページは入会対象外のユーザーへの"逃げ道"ページ
- 基本的に入会フロー（`/join`）またはお問い合わせ へ誘導する目的
- 対象外ユーザーの定義：青山学院大学に在籍していない、入学見込みもない等

## 実装メモ

- `join.module.css` から共通スタイル `heroNonMember` を適用
- リンクは `Link` コンポーネント使用（クライアントサイドナビゲーション）
- CSS クラス組み合わせで視覚的な区別を図る
