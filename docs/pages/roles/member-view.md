# ロール管理 一般メンバー表示仕様 (`MemberSelfView`)

本ドキュメントは、一般メンバー（`app_role === "member"`）としてログインした際に `/roles` で表示される個人用ロール管理ビュー（`MemberSelfView`）の画面要件・操作仕様です。

---

## 1. 概要
一般メンバーはサーバー全体のロール構成編集は行えず、**自分自身に対するセルフロール（関心分野、学年、サークル内チーム等）の付与・解除** のみ行えます。
UI上で変更をトグル選択し、「変更を保存してDiscordへ反映」ボタンを押すことで、DBおよびDiscordサーバーと自動同期されます。

---

## 2. 画面構成要素

1. **ユーザープロフィールヘッダー**:
   - Discord アバター、表示名、現在の権限（`member`）を表示。
   - ログアウトリンク（`/auth/signout?callbackUrl=/`）。
2. **ステータス・フィードバックバナー**:
   - 保存中（`saving`）、保存完了（`saved`）、エラー（`error`）の視覚的通知。
   - 未保存の変更がある場合のインジケータ。
3. **ロールカテゴリ一覧（アコーディオン）**:
   - カテゴリ単位で展開／折りたたみが可能。
   - カテゴリ内のロール一覧と、現在の自身への付与状態（チェックマーク／トグルボタン）。
4. **保存・同期アクションバー**:
   - 「変更を保存してDiscordへ反映」ボタン。
   - 変更がある場合のみ活性化。

---

## 3. 操作フローと制約

### 操作フロー
1. **ロールの選択・解除**:
   - 自身に付与したいロールのチェックボックス／トグルをクリック（ローカル state で保持）。
   - 「未保存の変更があります」と画面に明示。
2. **保存と同期の実行**:
   - 「変更を保存してDiscordへ反映」をクリック。
   - 変更前後の差分を抽出し、追加されたロールには `/api/roles/self-assign`、削除されたロールには `/api/roles/self-remove` を発行。
   - 処理完了後、Discord サーバー側のロールが即座に反映され、成功メッセージを表示。

### 安全制約（Hierarchy Protection）
- **Bot 上位ロールの保護**: Discord Bot 自身の持つロール階層より上位のロール、および `is_restricted`（管理者限定カテゴリ）のロールは一般メンバーからは操作・選択できません（UI上で無効化表示）。

---

## 4. 仕様API（Route Handlers 経由）

- **ロール割当一覧取得**: `GET /api/roles/members`
- **セルフロール付与**: `POST /api/roles/self-assign`
  ```json
  { "role_id": "123456789012345678" }
  ```
- **セルフロール解除**: `POST /api/roles/self-remove`
  ```json
  { "role_id": "123456789012345678" }
  ```
