## 概要

在学生向け仮入会フォーム（`/join/form/aoyama-student`）は、青山学院大学の現役学生を対象とした仮入会ページです。学生番号から大学配布メールアドレス（`@aoyama.ac.jp`）を自動導出し、ワンタイムパスワード（OTP）認証を経て仮入会を完了させます。

## 主要要件

- 氏名（姓・名）の入力とバリデーション
- 学生番号の入力（正規表現 `/^[1234S][A-Za-z0-9]{7}$/`）
- 大学メールアドレスの自動導出（頭文字マッピング + `@aoyama.ac.jp`）
- 6 桁ワンタイムパスワード（OTP）モーダルによる即時メール認証
- 認証完了後の Discord サーバー招待リンク案内

## 非機能要件

- クライアントコンポーネント（React state によるリアルタイム導出）
- 学生番号・氏名のリアルタイムバリデーション
- 認証コード入力モーダル（`OTPModal`）によるシームレスな UX

## 必要項目・操作

### フォーム項目
| 項目 | 型 | 必須 | 検証 | 説明 |
|-----|-----|:---:|------|------|
| 氏名（姓・名） | text | ○ | 「姓 名」形式 | 2枠入力から自動結合 |
| 学生番号 | string | ○ | `/^[1234S][A-Za-z0-9]{7}$/` | 8桁の学生番号（先頭は1/2/3/4/S） |
| メールアドレス | email | ○ | 自動導出 | 学生番号から自動生成（編集不可） |

### 学生番号からのメール導出仕様 (`buildAoyamaEmail`)
- 先頭文字変換: `1 → a`, `2 → b`, `3 → c`, `4 → d`, `S/s → s`
- 後続 7 文字: 小文字化
- ドメイン: `@aoyama.ac.jp`（例: `15823001` → `a5823001@aoyama.ac.jp`）

## 操作フロー

1. **基本情報入力**
   - 氏名（姓・名）を入力
   - 学生番号を入力 → 有効な形式であれば即座にメールアドレスを自動導出・表示
2. **仮入会リクエスト**
   - 「認証コードを送信」ボタンをクリック
   - バックエンド `POST /api/v1/join/request` を呼び出し、導出された大学メール宛に 6 桁 OTP を送信
   - 画面上に `OTPModal` を表示
3. **OTP 認証**
   - 受信した 6 桁の認証コードをモーダルに入力
   - バックエンド `POST /api/v1/join/verify` を呼び出して検証
   - 認証成功時、仮入会完了画面（Discord 招待リンク表示）へ切り替え

## 仕様API

### 1. POST /api/v1/join/request
仮入会申請・OTP コード発行送信

**リクエスト**
```json
{
  "email": "a5823001@aoyama.ac.jp",
  "name": "青山 太郎",
  "form_type": "prospective-student",
  "metadata": {
    "student_id": "15823001"
  }
}
```

**レスポンス**
```json
{
  "status": "pending",
  "message": "Verification code sent to email"
}
```

### 2. POST /api/v1/join/verify
OTP コード検証・仮入会完了

**リクエスト**
```json
{
  "email": "a5823001@aoyama.ac.jp",
  "code": "123456"
}
```

**レスポンス**
```json
{
  "status": "verified",
  "invite_url": "https://discord.gg/xxxxxx"
}
```

## 関連DB

- `join_requests`: 仮入会申請レコード（`email`, `name`, `status`, `metadata`）
- `otp_codes`: ハッシュ化（bcrypt）された OTP コード、有効期限（10分）、試行回数

## 備考
- メール送信には Brevo API を使用。
- OTP 試行回数は最大 5 回でロックアウト。
- 本登録（正式メンバー化）は入会費支払い後に `/join/member` から行います。
