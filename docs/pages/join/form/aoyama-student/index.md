## 概要

在学生向け仮入会フォーム（`/join/form/aoyama-student`）は、青山学院大学の現在在籍生を対象とした仮入会ページです。学生番号からメールアドレスを自動補完し、学内メール認証で仮入会を完了させます。

## 主要要件

- 学生番号の入力
- メールアドレスの自動補完（`{学生番号}@aoyama.jp` パターン）
- 学内メール認証による仮入会
- メールアドレスの確認

## 非機能要件

- リアルタイム入力補完
- 学内メール形式の検証
- 非同期メール認証処理

## 必要項目・操作

### フォーム項目
| 項目 | 型 | 必須 | 説明 |
|-----|-----|------|------|
| 学生番号 | number | ○ | 8 桁の学生番号 |
| メールアドレス | email | ○ | 自動補完：`{学生番号}@aoyama.jp` |

## 操作

1. **学生番号入力**
   - 学生番号を入力
   - 自動的に `{学生番号}@aoyama.jp` をメールアドレスに反映

2. **確認・送信**
   - メールアドレス確認
   - 送信ボタン クリック
   - 学内メール認証プロセス開始

3. **認証メール受信**
   - 学内メールに認証リンク送信
   - ユーザーがリンククリック
   - 仮入会確定

## 仕様API

### POST /api/v1/members/pre_member/register
仮入会登録

**リクエスト**
```json
{
  "email": "string",
  "student_number": "string",
  "category": "aoyama_student"
}
```

**レスポンス**
```json
{
  "success": true,
  "message": "認証メールを送信しました"
}
```

## 関連DB

- `pre_members` テーブル
- メール認証トークンテーブル

## 備考

- 学内メールアドレスは `{学生番号}@aoyama.jp` 形式で固定
- メール認証は 24 時間有効（推定）
- 重複登録チェック実装推奨

## 実装メモ

- 学生番号から自動補完する際、入力変更時にメールアドレスも更新
- バリデーション：学生番号は数字のみ、8 桁
