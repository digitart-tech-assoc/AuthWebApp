## 概要

入会区分選択ページ（`/join/form`）は、ユーザーの属性に応じた入会フォームを提示するページです。在学生・入学見込み・その他の3区分から選択でき、各区分に合わせた仮入会フォームへ遷移します。本ページは認証不要です。

## 主要要件

- 入会対象者の分類案内
- 3区分の詳細説明
- 各区分への遷移リンク
- エラーハンドリング・不明点案内

## 非機能要件

- 静的ページ
- レスポンシブデザイン
- SEO 対応

## 必要項目・操作

### 入会区分
| 区分 | リンク先 | 対象者 | 認証方法 |
|-----|---------|--------|---------|
| 在学生 | `/join/form/aoyama-student` | 青山学院大学在学生 | 学内メール |
| 入学見込み | `/join/form/prospective-student` | 入学予定者 | メール認証（期限付き） |
| その他 | `/join/form/other` | 上記以外 | 詳細確認 |

## 操作

1. **ページロード時**
   - 3つの区分カード表示
   - 説明と案内メッセージ表示

2. **カード クリック**
   - 選択した区分の詳細フォームページへナビゲート

3. **お問い合わせリンク クリック**
   - `/contact` へナビゲート

4. **戻るボタン クリック**
   - `/join` に戻る

## 備考

- `?mode` Query パラメータは UI フィードバック用（実装予定の表示切り替え）
- 不明点はお問い合わせページへ案内
- バグ報告も推奨（フィードバック窓口）

## 実装メモ

- `searchParams` の `Promise<...>` 型対応：`await Promise.resolve(searchParams)`
- アイコン：`School` (在学生)、`UserCheck` (入学見込み)、`MoreHorizontal` (その他)
- ホバーアニメーション：スケール + 影 + ボーダーカラー変更
- 戻るボタン：`ArrowLeft` アイコン使用
