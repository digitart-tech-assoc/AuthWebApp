## 概要

入学見込み向け仮入会フォーム（`/join/form/prospective-student`）は、青山学院大学への入学が決定している方を対象とした仮入会ページです。メール認証で仮入会を受け付け、期間制限付きの招待トークンを発行します。年度チェックにより、フォーム受付期間を制限しています。

## 主要要件

- 年度・氏名・メールアドレス入力
- 期間制限チェック（フォーム受付判定）
- メールアドレスのMX レコード検証
- メールアドレスの確認
- OTP（ワンタイムパスワード）による認証

## 非機能要件

- リアルタイムバリデーション
- 非同期MX検証
- 期限外アクセス時のエラーメッセージ
- クライアントコンポーネント

## 必要項目・操作

### フォーム項目
| 項目 | 型 | 必須 | 説明 |
|-----|-----|------|------|
| 入学予定年度 | number | ○ | 例：2025 |
| 氏名 | text | ○ | 「姓<スペース>名」形式 |
| メールアドレス | email | ○ | RFC 5322 準拠 |
| メールアドレス（確認） | email | ○ | メールアドレスと同値 |

### 期間制限
- ページ読み込み時に `isProspectiveFormOpen()` でチェック
- 受付期間外の場合：警告メッセージ表示、フォーム送信無効化

## 操作

1. **ページロード時**
   - 期間チェック実行
   - 期間内：フォーム表示
   - 期間外：警告メッセージ表示

2. **年度入力**
   - 数字のみ許可
   - リアルタイムバリデーション

3. **メールアドレス入力**
   - MX レコード検証（非同期）
   - 検証中は「検証中...」インジケータ表示

4. **メールアドレス確認**
   - 両方のメールアドレス入力値が一致するかチェック

5. **OTP送信**
   - 検証OTPをメールに送信
   - OTP モーダル表示

6. **OTP入力・確認**
   - OTPコード入力（6桁推定）
   - 確認ボタン クリック
   - OTP 検証後、仮入会完了

## 仕様API

### POST /api/v1/members/pre_member/register
仮入会登録（入学見込み）

**リクエスト**
```json
{
  "email": "string",
  "name": "string",
  "year": number,
  "category": "prospective_student",
  "otp_code": "string"
}
```

**レスポンス**
```json
{
  "success": true,
  "message": "仮入会しました",
  "token_expires_at": "2025-06-30T00:00:00Z"
}
```

## 関連DB

- `pre_members` テーブル
- OTP テーブル（一時トークン）
- メール認証テーブル

## 備考

- 入学見込み者は期限付き招待（在学生と異なる扱い）
- 入学年度の確認により、実在する入学者を検証
- MX 検証がない場合でもフォーム送信可能（後続の工程で検証）
- 期間外アクセス時は警告しつつ、別パスでのお問い合わせ導線を提供

## 実装メモ

- `isProspectiveFormOpen()` は `lib/join.ts` で日付チェック実装
- MX 検証は Cloudflare DNS API使用
- OTP送信は `OTPModal` コンポーネント担当
- `validateFullName()` で「姓 名」形式をチェック
- 年度バリデーション：数字のみ、4桁推奨（例：2025）
