## 概要

その他向け案内ページ（`/join/form/other`）は、当サークルの入会対象外（青山学院大学以外の学生、卒業生、社会人など）のユーザーを案内するページです。入会条件の説明とお問い合わせ導線を提供します。

## 主要要件

- 入会対象外理由の明確化
- 代替案内（入学見込みフォームの紹介）
- お問い合わせ窓口の案内
- メール連絡先の表示

## 非機能要件

- 静的ページ
- レスポンシブデザイン
- セマンティックHTML

## 必要項目・操作

### ページ構成
| セクション | 内容 |
|-----------|------|
| ヒーロー | 「申し訳ございません」タイトル |
| 本文 | 当団体の入会対象条件説明 |
| 代替案内 | 青山学院大学入学見込み者向けリンク |
| お問い合わせ | フォーム・メールアドレス |

### 代替案内オプション
1. **入学見込みの場合**
   - `/join/form/prospective-student` へリンク

2. **質問・相談がある場合**
   - `/contact` へリンク
   - または `aoyama.tech.exe@gmail.com` へメール

## 操作

1. **ページアクセス時**
   - 入会対象外の理由を表示

2. **入学見込み者チェック**
   - ✓「青山学院大学への入学が決定している場合」
   - → 「入学見込みフォーム」リンククリック
   - → `/join/form/prospective-student` へ遷移

3. **お問い合わせ選択**
   - 「お問い合わせフォーム」リンク → `/contact`
   - または メールアドレスクリック → メーラー起動

4. **戻るボタン**
   - 前ページに戻る

## 備考

- 本ページは入会フローの"dead end"ではなく、代替案内を提供
- 丁寧で親切なトーンを維持
- メールアドレス表示は `break-all` クラスで改行対応
- リンク要素は視覚的に目立つ色（emerald）を使用

## 実装メモ

- Info アイコン、Check アイコン、Mail アイコン使用（Lucide React）
- グラデーション背景：`from-amber-50 to-teal-50`
- リンク先に応じた色分け：emerald (推奨)、slate (代替)
- CSS Grid で 2 列レイアウト実装（レスポンシブ）
